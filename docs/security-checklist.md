# 보안 체크리스트 초안

## 인증/인가

- 이메일 인증 도입 여부 결정
- 비밀번호 해시 저장
- 로그인 시도 횟수 제한
- 비정상 로그인 탐지
- 관리자 계정 분리
- RBAC 적용

## 세션/쿠키

- HttpOnly 쿠키 사용
- Secure 쿠키 사용
- SameSite 정책 적용
- 세션 만료 및 갱신 전략 정의

## 결제

- 결제 Webhook 서명 검증
- 금액/주문번호 재검증
- 결제 중복 처리 방지
- 환불 및 취소 감사 로그 기록

## 크레딧

- Ledger 기반 차감/충전 이력 보관
- 모든 차감 연산에 idempotencyKey 사용
- 실패 시 보상 트랜잭션 처리

## AI 및 파일 처리

- 프롬프트 인젝션 방어를 위한 입력 정제
- 민감정보 비전송 원칙
- PDF 파일 접근 권한 통제
- 다운로드 URL 만료 처리
- 생성 파일 악성 업로드 차단

## 인프라

- 비밀키는 환경변수 또는 Vault로 관리
- DB 접근 최소 권한 원칙
- HTTPS 강제
- 운영/개발 환경 분리
- 로그 마스킹 적용

## 애플리케이션

- Zod 등으로 입력 검증
- CSRF 보호
- SSRF 방어
- 업로드 MIME 검증
- SQL Injection 방어
- Dependency 취약점 점검
