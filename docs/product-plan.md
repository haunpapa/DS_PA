# 부동산 입지 분석 보고서 서비스 기획

## 1. 서비스 목표

사용자가 특정 지역 또는 주소를 입력하면 AI가 입지 분석 보고서를 생성하고, 이를 PDF로 내려받을 수 있는 유료 SaaS를 구축한다.

핵심 경험은 다음과 같다.

1. 회원가입 또는 로그인
2. 크레딧 충전
3. 주소 또는 지역 입력
4. 보고서 옵션 선택
5. AI 분석 실행
6. PDF 다운로드 및 이력 조회

## 2. 핵심 가치 제안

- 빠른 보고서 생성: 사람이 리서치하던 시간을 AI로 단축
- 일관된 형식: 표준화된 PDF 보고서 제공
- 재사용 가능: 과거 보고서 이력 보관 및 재다운로드 지원
- 수익 구조 명확화: 보고서 생성 시 크레딧 차감

## 3. 핵심 사용자

- 공인중개사
- 부동산 투자자
- 분양/개발 검토 담당자
- 지역 상권/입지 리서치가 필요한 일반 사용자

## 4. 주요 기능

### 필수 기능

1. 부동산 입지 분석 보고서 생성
2. 생성 시 크레딧 차감
3. 회원가입, 로그인, 프로필 관리
4. 결제 및 크레딧 충전
5. PDF 파일 생성 및 다운로드
6. 생성 이력 조회
7. 관리자용 운영 기능

### 추가 권장 기능

1. 보고서 초안 미리보기
2. 생성 실패 시 자동 환불 또는 보류 처리
3. 지역별 템플릿
4. 법적 고지 및 면책 문구 자동 삽입
5. 관리자 대시보드
6. 사용량 및 비용 모니터링

## 5. 보고서 구성안

보고서는 최소 아래 섹션을 포함한다.

1. 대상 지역 개요
2. 교통 접근성
3. 생활 인프라
4. 교육 환경
5. 개발 호재 및 규제 리스크
6. 수요/공급 관점 요약
7. 투자 관점 종합 의견
8. 유의사항 및 면책 문구

## 6. AI 처리 전략

권장 흐름은 아래와 같다.

1. 입력값 정규화
2. 데이터 수집 및 프롬프트 컨텍스트 구성
3. Gemini로 분석 초안 생성
4. Claude로 PDF용 문서 구조화
5. HTML 템플릿 렌더링
6. PDF 엔진으로 최종 PDF 생성

참고:
Claude가 직접 바이너리 PDF를 생성하는 방식보다, Claude가 구조화된 Markdown/HTML 문서를 만들고 서버가 이를 PDF로 렌더링하는 구조가 구현 안정성과 품질 면에서 더 좋다.

## 7. 크레딧 정책 초안

- 보고서 1건 생성 시 기본 1 크레딧 차감
- 프리미엄 옵션 선택 시 추가 차감 가능
- 생성 실패 시 환불 규칙 필요
- 차감 내역은 Ledger 방식으로 보관

## 8. 결제 정책 초안

- 상품 단위: 크레딧 패키지
- 결제 완료 후 크레딧 충전
- 결제 취소/환불 시 반영 규칙 필요
- 결제 Webhook은 검증 및 재처리 가능 구조 필요

## 9. 운영 관점 요구사항

- 보고서 생성 성공률 모니터링
- AI 호출 실패율 추적
- 사용자별 크레딧 원장 확인
- 결제 이벤트 감사 로그 보관
- 관리자용 수동 재시도 기능

## 10. MVP 범위

MVP에서는 아래 범위까지 우선 구현한다.

1. 이메일 기반 회원가입/로그인
2. 크레딧 구매
3. 보고서 생성 요청
4. 생성 중/완료/실패 상태 관리
5. PDF 다운로드
6. 마이페이지 생성 이력 조회
7. 관리자 기본 모니터링
